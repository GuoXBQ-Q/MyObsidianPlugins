# MyCalendar

一个 Obsidian 日历日程插件：支持 **日 / 周 / 月 / 日程** 四种视图、**农历与节气节日** 显示、**法定节假日调休（休/班）标记**、**今日圆圈标注**、**重要事件单元格高亮**，点击任意日期即可添加日程；还能把月历**作为组件注册进 Home Widgets** 首页。

## 功能

- **月视图**：经典 6×7 月历网格，每天显示公历日期 + 农历 + 节日/节气（红色角标）+ **法定节假日「休」/调休「班」角标**；有日程的日期单元格带柔和底色，**重要事件**当天单元格高亮描边突出；**今天**用圆圈标出；每天最多显示 3 条日程 chip，更多点击"还有 N 项"跳转日视图。
- **周视图**：7 列时间轴（可配置显示小时范围），事件按时间定位成色块，重叠自动分列，显示"现在"红线；顶部有全天事件栏；列头带休/班标记，点击跳转日视图；点击空白处按吸附时间（15 分钟）新建。
- **日视图**：单日 24 小时时间轴 + 全天事件 + 当日农历/节日/休班信息。
- **日程**：所有日程按日期分组的列表，未来/过去一目了然，"今天"有角标。
- **新建/编辑日程**：标题、日期、开始/结束时间（留空 = 全天）；日期与小时/分钟使用统一主题的悬浮选择框，贴近各自输入框弹出并自动避让窗口边缘，点击外部或按 Escape 收起；支持切月、回到今天、直接输入日期和任意分钟；18 种分类颜色、色盘、HEX 色号及屏幕取色（环境支持时启用），自动记住最近 12 个已保存的自定义颜色；⭐重要标记、备注；编辑模式支持删除（二次确认）。
- 顶部日期、胶囊形视图切换栏和 `‹ 本月 ›` / "新建"按钮同排对齐，空间不足时切换栏另起一行。新建/编辑弹窗中「跨天日程」与「重要事件」使用可整卡点击的选项卡，不显示副说明；选中状态和日期范围提示跟随主题色。跨天时按开始日期/时间 → 结束日期/时间排列，并实时显示包含首尾两天的天数；窄屏自动换行。
- **跨天日程**：勾选「跨天日程」，填写日期与结束日期，包含首尾两天。例如「天津会议活动，2026-11-06 至 2026-11-09」只保存为一条日程；独立月历与首页组件显示跨格横条，跨周、跨月继续显示，重叠日程自动分行。点击任一段可编辑或删除整条日程；悬停显示完整日期范围与备注。日/周视图在顶部「全天 / 跨天」栏显示，日程列表只列一次并显示完整范围。
- 支持深色/浅色主题，跟随 Obsidian 主题变量。
- **同日日程排序**：设置中的「新日程显示在下方」默认开启，按添加顺序排列同一天的日程，编辑标题或时间不会改变顺序；关闭后恢复按开始时间、标题排序。独立月历、首页组件、全天/跨天栏和日程列表同步生效，日/周时间轴仍按实际时间定位；跨天横条保留独立区域。
- 独立日历页面随窗口可用高度伸缩；月历按内容保留最小行高，其余空间自动分配，窗口较矮时在日历内部滚动，顶部工具栏保持可见。
- 独立页面顶部和两侧保留 16px 间距，底部保留 32px，为 Obsidian 右下角提示留出空间；日/周视图使用细滚动条，悬停或键盘聚焦时显示。周视图的日期表头、全天栏和时间列共用滚动宽度，滚动时表头保持可见。

## 农历、节日与法定节假日数据

- **农历 / 二十四节气 / 传统节日**：纯算法计算（查表法，1900–2100 年），无需联网、无需维护数据。
- **法定节假日与调休（休/班）**：国务院每年年底才发布下一年安排，无法推算。数据有两个来源：
  1. **内置数据**：`src/holidays.ts` 的 `ARRANGEMENTS`，目前收录 **2025、2026** 年（来源：国办发明电〔2025〕7号等官方通知）。
  2. **在线获取（推荐）**：设置 → MyCalendar → 「在线获取节假日安排」，输入年份点「获取」即可。依次尝试 holiday-cn（jsDelivr CDN → GitHub）和 timor.tech 三个数据源，取到的数据存入 `data.json`，**无需改代码、无需重新构建**。查询优先级：在线数据 > 内置数据 > 法定节日估算。
  - 官方一般每年 **11 月底**发布下一年安排，发布前获取会失败，属正常现象。
  - 内置 2026 数据已与 holiday-cn 官方同源数据做过全年逐日比对，完全一致。

## Home Widgets 集成

安装并启用 [Home Widgets](../HomeWidgets) 后，MyCalendar 会**自动把月历注册为它的一种组件类型**（通过宿主公开的 `api.registerWidget`，不修改宿主工程）：

- 打开 Home Widgets 首页 → 右上角「添加组件」→ 选择 **MyCalendar 日历**，可以创建多个实例（各自独立的月份视图与配置）。
- 组件功能：月历网格（农历 / 节日节气 / 休班角标 / 今日圆圈 / 重要事件高亮）、`‹ 本月 ›` 切换、点击日期新建日程、点击日程编辑、「还有 N 项」跳转 MyCalendar 日视图；右上角「＋ 日程」快速新建今天日程。
- 实例设置里可单独开关：显示农历 / 显示节日与节气 / 显示休班角标。
- 日程数据仍保存在本插件的 `data.json`，所有视图与组件共用一份；保存后组件实时刷新。
- 注册时机：本插件启动时会等待 Home Widgets 加载（每秒重试，最长 60 秒）。若先启用本插件、超过一分钟后才启用 Home Widgets，重新启用一次 MyCalendar 即可。

## 命令

- `打开日历视图` / 左侧 ribbon 日历图标
- `新建日程（今天）`

## 设置

设置 → MyCalendar：默认视图、周首日（周一/周日）、显示农历、显示节日与节气、显示法定节假日调休、**在线获取节假日安排（手动按钮）**、时间轴小时范围。

## 数据存储

日程数据保存在插件目录的 `data.json`：

```
.obsidian/plugins/my-calendar/data.json
```

备份 vault 时记得带上该文件（Remotely Save 等同步不会同步 .obsidian 下的 data.json 时请注意）。

单日日程使用 `date`；跨天日程增加可选的 `endDate`（`YYYY-MM-DD`，包含结束当天）。结束日期不能早于开始日期；开始/结束时间表示首日开始和末日结束，不会在每天重复。取消勾选跨天日程会恢复为开始日期当天的日程；日期相同仍按单日时间顺序校验。全天跨天日程将时间留空即可。

## 开发

源码位于 vault 根目录的 `MyCalendar/`，安装目录为 `.obsidian/plugins/my-calendar/`。在源码目录运行：

```bash
npm ci             # 按 package-lock.json 安装依赖（首次开发或依赖变化时）
npm run dev        # 开发构建（带 inline sourcemap）
npm run build      # 生产构建 -> build/，不修改已安装插件
npm run deploy     # 生产构建并复制三个安装文件，保留实际 data.json
npm run typecheck  # tsc 类型检查
npm test           # 日期范围、跨周排布、重叠与边界行为测试
npm run preview    # 本机弹窗预览（127.0.0.1:8789），点击“运行交互测试”执行回归检查
```

修改源码后运行 `npm run deploy`，然后在 Obsidian 中关闭再开启本插件（或 Ctrl+R 重载）即可看到效果。构建结果位于 `build/`，该目录不纳入 Git；`styles.css`、`manifest.json` 和 `package-lock.json` 属于源码，纳入 Git。

弹窗预览沿用本机 Obsidian 的基础样式；验证数据仅保存在内存，支持深浅色和窄屏检查，不会读取或改写真实日程。屏幕取色的回归检查使用模拟接口验证结果保存和降级，实际取色使用当前环境的 EyeDropper 能力。

预览默认使用端口 8789；如已被占用，可在 PowerShell 中先设置 `$env:MY_CALENDAR_PORT = '8790'`，再运行预览命令。
